# Контрольные вопросы
### 1. Чем отличается Git от GitHub?
Git - система контроля версий. GitHub - сервис для хранения кода в облаке.
### 2. Для чего используется виртуальное окружение Python?
Виртуальное окружение Python нужно для соблюдения "чистоты" проекта. Оно позволяет устанавливать библиотеки независимо от глобального Python, фиксировать зависимости внутри проекта и устранить проблему совместимости между версиями библиотек разных проектов.
### 3. Что такое commit, branch, remote, pull request?
* commit - версия проекта с конкретным авторством и комментарием
* branch - ветка проекта для безопасной работы над отельными частями проекта
* remote - удалённый репозиторий, например, на GitHub
* pull request - запрос на объединение коммитов с существующей веткой
### 4. Зачем нужен файл .gitignore?
Содержимое файла .gitignore определяет, какие файлы и папку не будут добавляться в репозиторий. Это необходимо для сохранения конфиденциальности, безоопасности и соблюдения чистоты проекта.
### 5. Как организовать командную работу над бизнес-приложением с помощью Git?
Командная работа организуется через работу в отдельных ветках, позволяющих разрабатывать, контролировать, тестировать и добавлять не весь проект целиком, а его отдельные части, что обеспечивает большую стабильность. Перед внесением изменений в основную версию проекта, разработчики их проверяют.
Кроме того, Git позволяет добавлять комментарии к веткам и изменениям (коммитам) в них, что позволяет отслеживать историю разработки и составлять документацию без необходимости гадать, что имел в виду другой разработчик. Этим обеспечивается прозрачность процесса разработки.
### 6. Какие файлы обязательно должны быть в репозитории учебного проекта?
* README - файл для объяснения, чем является проект, что он делает, для чего, как его запускать и т.д.
* .gitignore - для соблюдения безопасности и чистоты проекта
* requirements.txt - список использованных библиотек Python и их точные версии
* файлы с выполнением заданий проекта
### 7. Что произойдёт, если два разработчика изменят один и тот же файл в разных ветках?
В зависимости от внесённых изменений, может ничего не произойти, или случиться merge conflict, если изменилась одна и та же строчка кода. В таком случае нужно будет вручную решить, какую версию оставить.
